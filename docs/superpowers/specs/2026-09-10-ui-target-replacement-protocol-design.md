# UI目标替换协议设计

日期：2026-09-10

## 目标

当同一个RID从旧UI目标轨迹切换到新UI目标轨迹时，在新目标的`0x02`状态包中携带旧UI `target_id`，让UI立即删除仍处于10秒外推期的旧轨迹，避免同一RID目标在态势图上同时显示两条轨迹。

## 修改边界

本次只修改UI状态包编码、RID到UI身份的发送侧状态和模拟UI接收器。RID/SORT关联算法、`ui_tracks`筛选、SORT生命周期、距离裁决、云台控制、打击端协议和GPS协议保持不变。

所有RID均启用替换通知。没有RID绑定的视觉目标不建立替换关系，替换字段固定为0。已经被RID确认替换的旧UI ID，不允许仅凭视觉距离重新发送，直到该UI ID重新获得任意RID正式绑定。

## 协议

`0x02`由`!BB8sIffff`改为`!BB8sIffffI`，包长由30字节变为34字节。新增末尾字段：

- `replaced_target_id`：网络字节序`uint32`。
- `0`表示无旧目标需要删除。
- 非0表示UI应按全局`target_id`立即删除该旧轨迹。

追踪端和UI端同步升级，不兼容旧版30字节状态包。`0x03` GPS包和打击端包不变。

## 状态模型

发送侧按现有`rid_item["key"]`为每个RID独立维护：

- `bound_ui_id`：该RID最近一次接受的UI目标ID。
- `pending_replacements`：FIFO删除通知队列，每项包含`old_ui_id`和`remaining`。
- `superseded_ui_ids`：该RID已经替换、禁止凭视觉距离重新发送的旧UI ID集合。

首次绑定只记录`bound_ui_id`，不产生删除通知。同一RID绑定到不同UI ID时，将旧ID标记为已替换并以`remaining=3`加入队列，然后更新`bound_ui_id`。

每个成功发送的有效`0x02`包最多携带队首旧ID一次，并将其`remaining`减1；无有效距离、没有发包或本地UDP发送失败不减次数。减到0后移除队首。快速连续切换按FIFO依次通知，已在队列或已标记的旧ID不重复入队。

## 当前绑定保护

每个发送周期先批量登记全部当前RID到UI ID的绑定，再决定删除字段，避免多RID遍历顺序影响结果。

只要某个UI ID当前正式绑定任意RID，就从所有待删除队列和已替换集合中移除该ID。这样不会删除已经由另一RID接管或重新恢复RID身份的目标。

## 与轨迹生命周期的关系

旧目标在`UI_MAX_LOST_SECONDS=3s`内仍属于`ui_tracks`时，现有RID粘滞绑定继续保持，不产生切换。

旧目标退出`ui_tracks`但仍在内部保留期内时，不因退出本身产生替换。若随后恢复为相同UI ID，不产生替换；若同一RID正式绑定不同UI ID，才产生替换通知。

RID短时失效、6秒距离过期或暂时没有UI目标时保留状态。RID连续300秒无上报并由`RIDTrackManager`永久删除时，清除该RID的绑定、队列和已替换状态。程序重启时状态重新开始。

## UI发送规则

现有“仅正数有限距离才发送`0x02`”规则保持：

- RID绑定目标：根据对应RID状态携带队首`replaced_target_id`，无待办则为0。
- 无RID绑定的视觉目标：`replaced_target_id=0`；若其UI ID已被标记为已替换，则整包跳过。
- UI发送成功后才消耗一次替换重发次数。

## 日志

在现有通用事件日志中增加最少量事件：

- `RID_UI_ID_SWITCH`
- `UI_REPLACEMENT_SEND`
- `UI_REPLACEMENT_COMPLETE`
- `UI_SUPERSEDED_TARGET_SKIP`
- `RID_UI_REPLACEMENT_STATE_DELETE`

事件记录RID标识、旧/新UI ID和剩余次数，不改变其他结构化日志语义。

## 测试

自动测试覆盖：

- 34字节协议、网络字节序和默认0字段。
- 单RID切换后旧ID恰好随3个成功包发送。
- 无距离或发送失败不消耗次数。
- 多RID状态隔离和快速切换FIFO。
- 相同UI ID恢复不产生替换。
- 已替换ID不能凭视觉距离重新发送。
- UI ID重新绑定任意RID后取消抑制和待删除任务。
- RID永久删除时清理状态。
- 原有无距离不发送行为继续成立。

## 风险与验证

主要兼容风险是旧UI无法解析34字节包，部署时必须同步升级UI。该修改不触碰硬件控制路径，没有新增云台运动风险。

联调时应验证UI对重复删除同一ID保持幂等，并覆盖同ID恢复、新ID换代、快速连续换代、UDP丢包以及视觉旧轨迹恢复场景。
